# 第二十八章 · 半口

「你按。」沈衡说。沙。两个字。

风铃看他。看开过缝的那只铃。看他没放。没放是还。还过。还过她知道。知道不提空桌。提了这座塔会变成那间房。那间房她不进。不进她点头。点头把掌心更死地按在裂纹上。中音。低。音叉。自己的铃贴上去。贴。对拍。一对。二对。三对。第四下没有高。没有高对不齐。对不齐她咬牙。咬牙中音硬顶。硬顶裂开一线。一线白。白朝外。朝抽的方向。抽的人是收货的那个。那个补箍的铜掉了。掉。钟自己闷响一声。闷。不是齐。是半口还在。还在泵不成。泵不成雾仍当路。路窄。窄能走。走不是来回咬岸。咬岸那一层被她按死。按死她腿软。软一百四。软他没扶。没扶她自己撑着钟腰。撑着。耳尖红。红不是情欲。是用力。用力没有高音。没有高音仍按住了。按住收货的人看了他们一眼。一眼像看两口不配套的铃。不配套仍响过一下。响过半口。半口够这座塔暂时不死。不死门不塌。不塌出不去。出不去他们还在同一张图里。同一张图里那人把补箍的铜收进怀里。收。「半口。又是半口。半口你们能活到雾散。雾散是哪一天我不管。不管我走。走钟归你们。归你们守着。守着别齐。齐了我再来收全口。」

他说完踏板。板漂。漂进雾。无旗那盏不转的灯跟了一段。跟不靠。靠月牙和量路都没动。没动两艘船第一次停在同一片白里。白里塔。塔上两个人。两个人之间有一口差半拍的钟。差半拍被按住了。按住了暂时。暂时她的手还在钟腰上。还在抖。抖他看着。看着没伸手。没伸手是她说过不要按。不要按他记得。记得灯暗过。问过持铃。她说不要按。不要按渡被按过。第八道在按。那一夜他仍把别的全踩碎了。踩碎了账他以为平。平了她走。走了别跟。别跟他上了量路。量路进了第二艘不该进的门。门里看见她按钟。按钟没有喊他的名字。没喊他也不喊。喊雾会唱。唱过沙。唱过先这个。先这个不在这座塔上说。

老单在梯子下面。探头。看见两个人。看见钟卫的楼印。楼印他在东港见过。见过不说话。说话问风铃：「还活着？」

「活着。」风铃说。中音。哑。用力过。「半口。暂时。你们……月牙先离塔。离塔守着船员。船员有绳。绳不在这里。这里没有土。」

「你呢。」

「我守这口。」她说，「守到雾散。散了我走。走不跟船回东港。回东港踏土。踏土成灰。灰不加阿嫂的油。」

老单看了沈衡一眼。一眼很短。短像量过。量过不评。不评他下梯子。下。月牙的辅机咳起来。咳着离。离量路还停着。停着钟卫在甲板上骂第二艘。骂完看见他在塔上。塔上有修铃的。修铃的耳。一百四。骂声小了。小了不是礼貌。是不知道这算不算文书。文书是护粮。护粮沉了。沉了哑铜在他口袋里。口袋里烫。烫他仍站着。站着风铃的手从钟腰上拿开。拿开腿还软。软她坐在塔板上。坐。一百四。箱子不在。箱子在月牙。月牙离了。离了她没带伞。没带伞雾里没有沿。没有沿她把铃按在疤上。按。凉。凉着不看他。不看他说：「门外进不来。进来是钟要死。死你进来。进来不是跟。」

「不是跟。」他沙，「文书。护粮。哑的从海上来。」

「沉了。」她说。

「嗯。」

两个人又停住。停住塔里只有雾。雾不唱。不唱比唱难。难她把第四下没对上的那截气喘匀。喘匀：「你的纹还是短。短的没有以前。」

他没接。接了要把空白借出去。借出去还不起。还不起他看她疤。疤白。白的时候他上船那夜还是红的。红的在空桌。空桌他以为结完。结完看见白。白像过了月。月时间湾。湾她不踏土。不踏土疤自己旧了。旧了他没资格问疼不疼。问了像账。账不平。不平他知道一点点。一点点从月台开始。从哑铜开始。从第二艘进不去开始。开始不够忏悔。不够仍比第七街那夜多。多他不说。不说把开过缝的铃垂着。垂着铃口朝下。朝下。

「别放。」她说。

「没放。」

「那口会按。」

「知道。」

她点头。点头是那一夜唯一还在的一句。不要按。不要按他今夜做到了。做到了别的没做到。没做到的不在这座塔上算。这座塔上只算半口。半口她按住了。按住了雾当窄路。窄路他们都出不去。出不去要守。守到雾散。散是哪一天收货的人不管。不管他们要在没有土的塔上过夜。过夜不是空桌。空桌有灯。有她说的灯。有先这个。先这个不在这里。这里有钟。有差半拍。有两个不说话的人。不说话的人第一次被危难按在同一张图里。按在。不是爱。爱还早。早的那一层若要来，来之前先把钟守住。守住她闭眼。闭眼不是睡。是没高音的那一截还在抖。抖他看着。看着没扶。没扶她自己躺到塔板上。躺。铁凉。凉着铃在胸口。胸口疤白。白着他靠着钟腰坐下。坐下距离刚好听第四下。第四下暂时不空。不空他守。守蜡还封着另外两只。封着。月牙的咳在很远的地方。很远。量路的人在门里。门里没有第三艘。没有。雾白。白着这一夜不是纯爱。纯爱要账先被看见。看见才有下一章。下一章若有人开口，开口不是先这个。是别的。别的今晚没有。没有她睡。睡他醒着。醒着听钟。听钟半口。半口。
