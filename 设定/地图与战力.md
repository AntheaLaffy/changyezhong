# 地图与战力 · 无限流 · 海图阶段

图可无限开，世界观可完全不同。卷一澜港已合。下一阶段**矛盾在海，不在陆**。男女主分别、不同理由、不同时段远航。整张海图对角色是迷雾——他们从未远航。

第四天灾：见 `第四天灾-封笔.md`。本阶段当原生航海神话写。一笔不露。

## 建筑基调（钉死）

**近海近代。** 与已写的澜港咬合：石钟楼、电车、煤气灯、电台、夜车、木梯铁门。

海上：木壳铁肋、帆为主、小蒸汽辅机、煤灯、雾笛、灯塔、手绘海图（外缘涂黑）。不是集装箱，不是玻璃幕墙，不是唐城飞檐当主街。

雾里可以出现**更旧**的东西（ trop 帆、无旗、船上长满灯）。那是神话船，不是把主世界改成中世纪。陆上港口仍是近代。幻想建筑只许长在雾里、船上、岛上那些「不该存在的轮廓」。

## 恒量（跨图仍带）

1. 她的铃（原住民。记忆完整。）
2. 借声必还
3. 辨纹
4. 那一夜（高音已填进第四下）
5. 他的空白（失忆外来者。无童年层。真因封笔。）

进图可翻译、可削。不叠第六等。不露面板。

枢纽仍是钟楼。入图：铃里存过的世界，敲对了进。海图阶段入图的皮是：**驶进雾 = 驶进一口很大的铃里还在响的那些。** 角色不知道「图」。他们只知道雾外没有可靠的图。

## 海图（迷雾）

澜港外海有一条**雾线**。渔船、班轮、钟卫艇都在线内转。线外在官方海图上是涂黑。老人说涂黑里有船自己在开。没有人从线外把日志写回来。

对风铃、沈衡：远航 = 第一次把船头对准涂黑。

陆不是本阶段主战场。港口只做出发、补给、错过。不下船开新的陆上政治线。

**分别远航（钉死）**

| | 风铃 | 沈衡 |
| --- | --- | --- |
| 何时 | 先。卷一夜车到东港之后转船。 | 后。隔开数周或数月。她已经进雾。 |
| 为何 | 陆上要拿嘴、要划户口。夜车只沿着湾。要离开潮域只能走雾线。另：船上有一口哑了的船铃，求修。修铃是她肯上船的面子。真因是正声还完、别跟、不能留。 | 不是跟她。文书：雾里失踪的船、海上来的哑铃。更深的：雾里有跟他一样没有来处的纹。牌可能已脏。 |
| 船 | 小货帆「月牙」。船员少。船铃挂在艏。 | 钟卫艇或商护「量路」。短、准、煤辅机。 |
| 见对方 | 本阶段默认不见。雾里可以看见**不是对方的船**。 | 同上。 |

禁止：同一条船、同一周出发、港口送行吻别、雾里第一夜就舷窗对舷窗。错过可以写。遇见要等危难图。

## 海上神话（原生，当真的）

选用、翻译进铃、两船各吃哪一口：见 `海上神话选用.md`。此处只留种子名。

雾里的东西用传说的名字在水手嘴里走，角色不当副本。

| 种子 | 一句 | 骨头 |
| --- | --- | --- |
| 无旗帆（荷兰人那种） | 灯不灭的船，逆风也能进。船上没有活人口供，只有铃还在响。 | 一口存着「整船还在响」的铃。靠近=入图。她修，他若后至则猎。 |
| 无人灯塔 | 雾线外仍在转的灯。灯油谁加的。 | 枢纽在海上的钉子。守灯人可能是守钟人的表亲职业。 |
| 岛不在图上 | 天亮有，雾里无。或反过来。 | 一天一图。不要当度假。 |
| 雾笛对频 | 有人用雾笛咬走灯塔的正声。西坡换皮。 | 抽声的海路。 |
| 沉船铜 | 澜港起源：第一口钟用沉船铜。雾里全是铜。 | 她听得见铜里的层。 |
| 人鱼/喉 | 可选。用声当饵。她失高音反而是护身。 | 不要写成恋爱。 |

飞翔的荷兰人号：用其结构（罚永恒航行、逆风、不靠港、船员非生非死），不必用版权原名。水手叫它**无旗**、**逆风的**、**灯不灭的**。正文不写荷兰。

## 本阶段地图卡

**M03 夜车** 已写。接到东港即止。

**M03b 东港** 类型：近代小港。只做换船。不下新陆线。建筑：煤栈、修帆棚、雾笛、一只锈锚。

**M14 雾线内** 类型：近海。规则：看得见岸。夜律松一点。仍有灯塔（澜港的或东港的）。

**M15 雾线** 类型：转场。规则：海图涂黑开始。罗盘乱。铃自己响。辨纹看见的纹不朝东，朝「里」。

**M16 无旗** 类型：神话船。世界观：船上的时间不走，铃不还。入图铃：艏铃或她带的船铃对上了。骨头：修，或拒绝修。爱情线：他不在。

其后雾里可无限加卡：灯塔、岛、另一条无旗、整座雾中港。类型不限，**入口都是海**。陆上大城先不开。

## 战力（海上）

五等仍翻译。船上持铃少。雾里放声会把别的船招来——贵。她的辨纹在雾里更清楚（声走不散）。他的短、准适合甲板。鸣钟级在雾里是灯塔和那口船铃。不要在甲板上街级清场。

失高音：雾笛、人鱼、需要高音对频的门，她过不去。拿来用。

## 卷一与海的接缝

第十四章她在夜车上。第十五章夜车到东港，雾线在港外。她上船。陆上矛盾放下（席、户口、第七街灯）——不是消失，是听不见。听见的是雾笛和船铃。

他仍在澜港段上走，直到后面某章文书叫他上船。两船日志分开写。
