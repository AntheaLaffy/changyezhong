# 如月风铃 · 故事总纲（澜港块）

全书脊柱是爱情线：先上车，后补票。见 `全书结构.md`。下文只管地图上第一块——澜港。

## 一句话

澜港用钟声印钱。有人偷钟声铸假铃。十九年前有人出声拦过，被消了音。如月风铃修好一枚不该修好的铃，开了浇口，被抄台；同一夜被误会送上床。她精神受创，仍把正声还进长夜钟，然后离开。

## 主题

声音是谁的。

这座城把声音做成货币、证据和武器。借出去一次，就要拿自己的嗓子还。能听的人多，能说的人少，能一辈子说话的一个也没有。风铃的全部成长，就是从一个只会替别人保管声音的人，变成一个肯把自己的声音留在世界上的人。

夜间电台不是人设点缀。那是政治。戌时之后只许刻铃发声——她每晚开播，本身就是在违规。

## 已钉死的规矩

- 铃只能存真正响过的声音，不能造，能剪。
- 借声必还：把铃里的声音放出去，代价是自己的嗓子。轻则哑，重则永久失声。
- 钱是刻铃。长夜钟每个时辰响一次就印一批。钟哑一分，钱就假一分。
- 风铃是辨纹：红眼看见声纹，蓝眼拆开重叠。辨纹是看，不是放，查案可以不花嗓子。**成年。** 一百四是身段。
- 白天困、夜里醒、月夜最好。对手会拿白昼卡她。
- 如月家从东方来，是为修这座塔。塔「修好了」，铺子留了下来。十九年前那句警告，跟这次迁徙叠在同一段时间上。
- 上一任守钟人如月渡（父亲的哥哥），名字不在户口上。划名的笔是如月岸的。条件：留铺、夜班、第二层不许说。夜班也是监视——席要如月的眼睛在塔下。
- 渡弄反了：还声没有条文。钟不吃还回来的人声，钟只吃自己的。借声必还，还的是人，不是钟。第九章若还声，还的必须是正声，不能是歌本身——歌是把正声送回去的音叉，不是填进空腔的人声。
- 武力阶层不扩：无耳 → 听声 → 辨纹 → 持铃 → 鸣钟 → 守钟人。持铃全城在册三十四人，钟卫十一人，鸣钟活着三个，守钟人一位。

## 真正在发生的事

长夜钟每补一次就哑一点，不是铜的问题。有人在偷钟声。

手法：在报时的那一拍里，用一口对频的私铃把长夜钟的正声吸走一截。吸走的那截拿去浇假刻铃——假铃里是真钟声，听声院听不出来。偷得越多，正钟越空，空到某一拍就响不出来。

第一章里那半拍的空白，是偷盗积累到临界。那枚裂了缝的刻铃，是十九年前被消音的人留下来的最后一声，被人当普通坏钱送到第七街。

十九年前：如月家渡海修塔。修到一半，家里有人听出钟声被抽。那人把警告敲进一枚刻铃，然后被「借声」借到再也开不了口。官方记录是事故。

**已锁定：C。** 如月家出过守钟人，后来被消音，现任是顶上去的哑巴。家、塔、嗓子三口钉子钉在一起。

风铃一直在修的，是自己家族没修完的那口钟。

## 三幕 · 十章

### 上 · 差一拍（第一至三章）

铺子接到那枚铃。她听见表层楼印底下压着男人的警告。当晚长夜钟少响半拍。听声院不认第二层。她用电台麦克风翻录。门外那条干净的持铃光纹停了三息。

下一章：钟卫上门要铃。电台开始来件。

### 中 · 十九年（第四至七章）

1. 守钟人。塔顶那位哑巴。第八道裂纹。他可能就是把那枚铃混进待修刻铃里的人。
2. 汐见。铸铃源头。夜行列车取证，不是游记。确认假刻铃的铜是不是长夜钟同炉。
3. 家里。父母知道。不全说。对质发生在夜里。
4. 钟卫沈衡。先挡，中段因假铃脏到粮饷而转立场。感情上一直不说。

底：假铃已经散进全城的钱里，揭开等于挤兑。

### 下 · 澜港收口（第八至十二章）

夜律收紧。电台被抄。同一夜误会上床：读错范围、结账的脏、要她的声音。停不下来。她精神受创，仍上塔还声。还声不是为他。代价：高音区回不来。还完她离开澜港。他以为账平，之后才看见自己做了抽声的同类。补票不在第七街。

## 风铃怎么长

1. 替别人保管声音。
2. 听见不该听见的，想推掉，推不掉。
3. 第一次把自己的声音当工具用（广播「假铃有抽纹」）。
4. 还声。歌和校准是同一件事。

怕生、慢半拍、被夸会卡壳、整点耳朵一缩、捏胸前那枚铃——全程留着。变的是捏铃的原因：从紧张，变成确认自己还在。

## 不写什么

- 不写成旅行见闻集。汐见只去一次，为铜。
- 不扩武力体系。
- 不开后宫、不搞无意义换装过场。
- 不让她白天突然生龙活虎。
- 不让铃读心、预言、造从没发生过的声音。第一章那句「还差一拍」是当事人看见偷法之后的判断。偷了十九年才偷到临界。
- 不让沈衡替她还声、替唱、罩着走。谁的时辰谁主事。
