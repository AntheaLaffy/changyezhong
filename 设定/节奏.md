# 节奏

主线要跑。日常也要写。日系西幻那种：迷宫后面有一顿饭，不是每一章都把刀架在脖子上。

## 松紧

- 一紧一松。大规矩后面必须歇。
- 禁止：两场神话连着打。禁止歇的时候用旁白把下一场剧透完。
- 沈衡那条船以后同样。

## 非主线 ≠ 流水账，也不等于只能写细节

主线是雾、铃、抽声、两人。非主线是歇下来时讲的**别的故事**。

可以很小：吊钩、袖口、哨。
也可以是一整章的旁支：老单把阿桃送衣那天的事讲完；灯塔阿嫂三年前那封没寄出的信；咳炭还过一截嗓子的那一晚。有头有尾，有人做出过一个选择。不是菜谱，也不是只能抖机灵细节。

日系西幻的歇，经常是「这一话不打Boss，打一桩人的事」。事可以轻，可以完整。完了再回主线。

| 不写 | 写 |
| --- | --- |
| 今天吃了什么、雾还是白 | 一件有因果的事：谁要了什么，谁没给，谁留下了 |
| 为了歇而描写动作清单 | 地着的一则完整小事／一段完整回忆／一次没有神话的冲突 |
| 用非主线给主线剧透 | 非主线自己能站住，拿掉主线仍值得读 |

篇幅随你：一节里的一件事，或整章旁支。地着优先。旅人不在的时候，世界仍发生这些事。

## 日常里仍在的骨头

日常不是把设定关掉。铃还在胸口。痂还在。她仍不听自己的声音。油罐子仍放在艏。只是今天没有人唱。

配角：见 `配角.md`。日常章优先给地着。地着不跟主角换地图。
