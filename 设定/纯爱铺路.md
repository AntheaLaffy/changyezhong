# 纯爱铺路

空桌是上车。塔上这一段才配补票。补票之前要放下滤镜。滤镜没放下就上床，是第二次结账，只是多了两句对不起。

## 滤镜

她看他：剪的人。要声音的人。灯一暗就会把半开做成全部。

他看她：可量的长度。可结的账。电台里那一层没处理过的声。

放下不是假装空桌没发生。空桌仍脏。谅解是看见对方不止那一笔。看见≠抹掉。纯爱是脏还在，仍选择下一次开口。开口要问。问了等。等了她说可以。可以才是可以。不是满了会说。

## 今晚不能做的

第二十九章已经钉死：别碰我。第二次没有。雾散各走各的水。

塔上第一夜上床不合理。危难刚按在一起，话才说到不平。立刻脱，滤镜还在。她会听见自己，会碎，会变成空桌续集。

## 合理顺序（章，可并可拆）

**1. 守。** 第四下空了叫她。他手悬在肩上三寸，收回。她睁眼看见收回。不谈爱。只看见「这次没按下去」。

**2. 不要她的声。** 她噩梦里出声，醒，要关。他背对。不看。不说「出声」。第一次把耳朵从她身上拿开。对照空桌专收那一层。这一下才配感动。

**3. 一件事，不是一场谈话。** 收货的人回来要全口。他手已经在蜡上。她看他。他把蜡按回去。不放。用别的方式挡——身体、哑铜、文书，不是持铃低频。钟不吃人声，他也不能替她唱第四下。他只能不抢她的按。

**4. 空白。** 她说：你没有以前。他第一次说：没有。不编还得太狠、不编无旗。她说：所以你剪。不是开脱。是看见算法从哪来。然后合同只有一句：**下次量之前问。**

**5. 坐近。仍别碰。** 滤镜裂开。还没放下。饼干、铁凉、听第四下。日系那种歇：有事，不是菜单。事就是「肩距从一尺变成半尺」。

**6. 开口。** 雾要散，或第四下又要空。她说可以。可以是手，是靠，是别走这一夜。不是先这个被剪。他问。问持铃。问碰哪。她说先手。**NSFW 从这里起。** 停就停。她听见表情也不立刻把脸闷死——闷死是空桌。纯爱允许被听见，仍难堪，仍要。

## NSFW（纯爱，等你开口再写）

对照空桌：

| 空桌 | 纯爱 |
| --- | --- |
| 剪成全开 | 问了等 |
| 要她出声 | 她出声也行，他不追着要 |
| 满了会说 | 事先可以说停 |
| 射在里面踩文书 | 她说了才 |
| 以为账平 | 知道不平，仍碰 |

做到哪、要不要写疤、要不要内射，仍等你定。剧情上只定：必须她开口。必须能停。不要按。

第三十四–三十八已写。三十六、三十七再扩：里面视角（裹、箍、刮肿、花芯）；烈处可叫夫君，平时沈衡／风铃。相互找。（朝上、半寸、刮不捅）、阴蒂、尾根、耳；点头才换；烈处互叫沈衡／风铃。不写夫君。两清仍在三十八。

## 谅解的温度

不要跪。不要长独白。不要「其实我爱你所以才剪」。剪就是剪。空白解释得了算法，开脱不了那一夜。她谅解的是：今夜没放、手收回、不要她的声、蜡按回去。谅解这些，才允许坐近。允许坐近，才可能开口。开口才是纯爱。纯爱才配身体。
